# สวนมะพร้าว

เว็บแอปสำหรับบันทึกรอบตัดมะพร้าว ดูรายรับ และติดตามกำหนดรอบตัดครั้งถัดไป รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์

## เริ่มใช้งาน

- ติดตั้ง Node.js 20.19 ขึ้นไป
- เปิดเทอร์มินัลที่โฟลเดอร์ suanmaprao-app
- รัน npm.cmd install เมื่อติดตั้งโปรเจกต์ครั้งแรกใน PowerShell
- รัน npm.cmd run dev เพื่อเปิดทั้ง API และหน้าเว็บสำหรับพัฒนา
- เปิด http://localhost:5173

หน้าเว็บใช้ React, Vite และ Tailwind CSS ส่วน API ใช้ Node.js หากต้องการรันแบบ production ให้ใช้ npm.cmd run build แล้ว npm.cmd start; เปิด http://localhost:3000

## ใช้ร่วมกันในบ้าน

ให้เครื่องที่รันแอปและอุปกรณ์ของคนในบ้านเชื่อมต่อ Wi-Fi เครือข่ายเดียวกัน ขณะพัฒนาให้เปิดเว็บด้วย IP ของเครื่องและพอร์ต 5173; แบบ production ใช้พอร์ต 3000 บน Windows ดู IPv4 Address ได้ด้วยคำสั่ง ipconfig และเปิดหน้าต่างเซิร์ฟเวอร์ค้างไว้ ทุกอุปกรณ์จะเห็นข้อมูลชุดเดียวกัน โดยหน้าเว็บจะดึงข้อมูลใหม่เป็นระยะ

หาก Windows ถามสิทธิ์เครือข่าย ให้เลือกอนุญาตเฉพาะเครือข่ายส่วนตัวที่ไว้ใจ แอปนี้ยังไม่มีระบบบัญชีผู้ใช้ จึงไม่ควรเปิดพอร์ตให้เข้าถึงจากอินเทอร์เน็ตสาธารณะ

ข้อมูลบันทึกไว้ใน data/garden.json บนเครื่องที่เปิดเซิร์ฟเวอร์ สำรองไฟล์นี้ไว้เพื่อเก็บข้อมูล

## Deploy บน Vercel

- `vercel.json` ตั้งค่า output directory เป็น `frontend/dist` และมี API route สำหรับ Vercel Functions
- ในโปรเจกต์ Vercel เปิด Storage แล้วสร้าง Blob store แบบ Private เพื่อให้ Vercel เพิ่ม `BLOB_READ_WRITE_TOKEN` ให้โปรเจกต์
- เพิ่ม Environment Variable ชื่อ `APP_PASSWORD` สำหรับ Production และ Preview ใช้รหัสผ่านยาวที่คาดเดายาก แล้ว redeploy
- สมาชิกในบ้านใช้รหัสผ่านแอปเดียวกันเพื่อเปิดข้อมูล ข้อมูลบน Vercel จะเก็บใน Blob แยกจาก `data/garden.json` บนเครื่อง จึงไม่ย้ายข้อมูลเดิมขึ้นไปให้อัตโนมัติ

## การคำนวณ

- รายรับของแต่ละรอบคำนวณจากจำนวนลูกคูณราคาต่อลูก ณ วันที่บันทึก
- การเปลี่ยนราคาในตั้งค่าจะใช้กับรอบใหม่ โดยไม่เปลี่ยนยอดขายในประวัติ
- วันตัดครั้งถัดไปคำนวณจากวันตัดล่าสุดบวกจำนวนวันต่อรอบที่ตั้งไว้
- สามารถแก้ไขหรือลบรอบตัดจากประวัติได้
